# Employee Resource Management System

## 📌 Project Overview

Employee Resource Management System (ERMS) is a web-based application designed to manage employee-related activities in an organization.

The system provides a centralized platform for managing employees, attendance, leave, tasks, payroll, notifications and other employee resources.

## 🚀 Features

- Admin Login
- Employee Login
- Employee Management
- Attendance Management
- Leave Management
- Task Management
- Payroll Management
- Notifications
- Employee Profile
- Contact Management
- Reports
- Resources Management
- Admin Dashboard
- Employee Dashboard

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
